# dotfiles

### Getting started

Run start

> $ ./start.sh

Install Brew

> $ brew bundle

Run stow

> $ stow -t <target_path> <package_name>

#### Prerequisites

- Git
- Homebrew

##### Optional

- GitHub Copilot
